# 08. コード定義

| 項目 | 内容 |
| --- | --- |
| 版 | 0.2（ステータス体系の改定を反映） |
| 目的 | 各テーブル・画面・IF で使う区分値を一箇所に定める。値の追加・変更は本書を更新してから各設計に反映する |

ステータスコード（STATUS_CD）の一覧は [03. ステータス定義・状態遷移](03-status-transition.md) を参照。

## 1. 会社区分（COMPANY_DIV）

| 値 | 名称 | 外部事前確認フロー | 備考 |
| --- | --- | --- | --- |
| 1 | 会社区分 1（名称は仮） | なし | 申込者同意後は最終承認申請待ちへ |
| 2 | 会社区分 2（名称は仮） | あり | 申込者同意後は事前確認待ちへ |

## 2. 権限（ROLE_CD）

| 値 | 名称 | できること |
| --- | --- | --- |
| 01 | 担当者 | 取込、新規申込・追加申込、入力・修正・確定、承認申請（回付先設定）、引戻し、同意後の修正、契約変更 |
| 02 | 承認者 | 承認、差戻し、審査申請（承認申請の回付先に設定された申請のみ） |
| 09 | 管理者 | マスタメンテナンス、全申込の参照、外部連携の再送 |

## 4. 操作主体（ACTOR_TYPE）

| 値 | 名称 | 操作者の照合方法 |
| --- | --- | --- |
| 1 | 申込受付会社（担当者） | 申込の担当社員 ID と一致すること |
| 2 | 申込受付会社（承認者） | 進行中の承認申請の現在ステップの承認者社員 ID と一致すること |
| 3 | 申込者 | 確認用トークンが有効で、対象の版が現行版であること |
| 4 | 審査担当部門 | 審査担当部門システムからの受信で IF 認証が正しいこと |
| 9 | なし | 操作なし |

## 5. 編集可フラグ（EDITABLE_FLG：ステータスマスタ）

| 値 | 名称 |
| --- | --- |
| 0 | 編集不可 |
| 1 | 申込受付会社（担当者）が申込内容を編集できる |
| 2 | 申込者が申込内容を編集できる |

## 6. 操作コード（ACTION_CD）

| 値 | 名称 | 操作主体 | 説明 |
| --- | --- | --- | --- |
| 00 | 新規作成 | 担当者 | 一括取込、画面からの新規申込、追加申込で申込を作成した記録。ステータス履歴のみで使う |
| 01 | 修正 | 担当者／申込者 | 入力中（または申込者の内容確認）へ戻して内容を修正する |
| 02 | 確定 | 担当者／申込者 | 入力・修正内容を確定する。申込者の内容確認の確定にも使う |
| 03 | 申請 | 担当者 | 承認フロー画面で回付先を設定して承認申請する |
| 04 | 承認 | 承認者 | 自分のステップを承認する。最終承認者の承認でステータスが進む |
| 05 | 差戻し | 承認者 | 申請待ちへ差し戻す。コメント必須 |
| 06 | 引戻し | 担当者 | 申込者確認中の申込を一次承認申請待ちへ戻す |
| 07 | 同意 | 申込者 | 申込内容に同意する |
| 08 | 申込者差戻し | 申込者 | 申込者が一次承認申請待ちへ差し戻す。理由を記録 |
| 09 | 審査申請 | 承認者 | 最終承認者が審査担当部門へ審査を申請する |
| 10 | 事前確認OK | 審査担当部門 | 事前確認結果「問題なし」を受信する |
| 11 | 事前確認NG | 審査担当部門 | 事前確認結果「修正必要」を受信する |
| 12 | 審査完了 | 審査担当部門 | 審査完了を受信する |
| 13 | 審査差戻し | 審査担当部門 | 審査差戻しを受信する |
| 14 | 契約変更開始 | 担当者 | 審査完了した申込の契約変更手続きを始める |

## 7. 条件コード（CONDITION_CD）

| 値 | 名称 | 判定方法 |
| --- | --- | --- |
| 00 | なし | 常に成立。同一の遷移元・操作の中では評価順を最後にして既定の遷移先とする |
| 11 | 回付先あり | 承認フロー画面で承認者が 1 人以上設定された |
| 12 | 回付先なし | 承認者が設定されていない（一次承認のみ可） |
| 21 | 変更基準超 | 現行版の申込金額 ÷ 基準版の申込金額 が、会社区分の金額倍率しきい値を超える |
| 41 | 初回の契約変更 | 申込の審査完了版の版種別が 1（新規申込） |
| 42 | 2回目以降の契約変更 | 申込の審査完了版の版種別が 3（契約変更） |

## 10. 申請状態（REQUEST_STATUS）

| 値 | 名称 | 説明 |
| --- | --- | --- |
| 1 | 申請中 | 回付中。現在ステップの承認者の操作待ち |
| 2 | 承認済 | 最終承認者が承認（最終承認では審査申請）した。回付先なしで直接進んだ場合もこの値 |
| 3 | 差戻し | 承認者が差し戻した |

| 値 | 名称 | 作られる契機 |
