# 08. コード定義

| 項目 | 内容 |
| --- | --- |
| 版 | 0.1（初版・ドラフト） |
| 目的 | 各テーブル・画面・IF で使う区分値を一箇所に定める。値の追加・変更は本書を更新してから各設計に反映する |

ステータスコード（STATUS_CD）は [03. ステータス定義・状態遷移](03-status-transition.md) を参照。

## 1. 会社区分（COMPANY_DIV）

| 値 | 名称 | 外部事前確認フロー | 備考 |
| --- | --- | --- | --- |
| 1 | 会社A（仮） | あり | 値・名称は仮置き |
| 2 | 会社B（仮） | なし | 値・名称は仮置き |

## 2. 権限（ROLE_CD）

| 値 | 名称 | できること |
| --- | --- | --- |
| 01 | 担当者 | 取込、入力・修正、承認申請・引戻し、審査中修正、修正対応、契約変更入力 |
| 02 | 承認者 | 承認、差戻し（承認ルート明細に登録された申請のみ） |
| 09 | 管理者 | マスタメンテナンス。全申込の参照 |

## 4. 操作主体（ACTOR_TYPE）

| 値 | 名称 | 操作者の照合方法 |
| --- | --- | --- |
| 1 | 担当者 | 申込の担当社員 ID と一致すること |
| 2 | 承認者 | 進行中の承認申請の現在ステップの承認者社員 ID と一致すること |
| 3 | 顧客 | 確認用トークンが有効で、対象の版が現行版であること |
| 4 | 外部システム | IF 用の認証情報が正しいこと |
| 9 | なし | 操作なし（終了ステータス） |

## 5. 操作コード（ACTION_CD）

| 値 | 名称 | 操作主体 | 説明 |
| --- | --- | --- | --- |
| 00 | 取込 | 担当者 | 一括取込で申込を作成した記録。ステータス履歴のみで使う（遷移マスタには載せない） |
| 01 | 修正 | 担当者 | 取込済の申込を修正する（0101 → 0102） |
| 02 | 確定 | 担当者／顧客 | 入力・修正内容を確定する。顧客の同意確定にも使う |
| 03 | 申請 | 担当者 | 承認申請する |
| 04 | 承認 | 承認者 | 自分のステップを承認する |
| 05 | 差戻し | 承認者 | 入力中へ差し戻す。コメント必須 |
| 06 | 引戻し | 担当者 | 申請者が申請を取り下げ、申請待ちへ戻す |
| 07 | 同意 | 顧客 | 申込内容に同意する |
| 08 | 審査完了 | 外部システム | 外部審査の完了を受信する |
| 09 | 確認OK | 外部システム | 外部事前確認の OK を受信する |
| 10 | 確認NG | 外部システム | 外部事前確認の NG を受信する |
| 11 | 契約変更開始 | 担当者 | 審査完了した申込の契約変更を始める |

## 6. 条件コード（CONDITION_CD）

| 値 | 名称 | 判定方法 |
| --- | --- | --- |
| 00 | なし | 常に成立。同一の遷移元・操作の中では評価順を最後にして既定の遷移先とする |
| 11 | 回付先あり | 承認ルートマスタ・明細に、申込の会社区分・部署・承認種別・当日に合うルートがあり、承認者が 1 人以上いる |
| 12 | 回付先なし | 11 が成立しない |
| 21 | 最終承認者以外 | 承認申請の現在ステップが最終ステップと一致しない |
| 22 | 最終承認者 | 承認申請の現在ステップが最終ステップと一致する |
| 32 | 倍率しきい値超 | 現行版の申込金額 ÷ 申込の基準金額 が、会社区分の金額倍率しきい値を超える |
| 33 | その他修正あり | 現行版のその他修正フラグが 1 |

元設計にあった「31：倍率しきい値以下」は、評価順と既定行（00）で表現できるため廃止した。
