# 画面の一括動作確認（Playwright）

`flow.js` は起動中のアプリに対してブラウザ操作で主要フローを一通り実行し、各ステータスへの遷移を確認する。

```bash
npm install playwright
npx playwright install chromium
BASE=http://localhost:8080 node e2e/flow.js
```

- 会社A：新規申込 → 申込メニュー（タイル固定の確認）→ SC05「修正」で 10201 → 10101 → 再確定 → 一次承認申請（申請者の承認フロー参照）→ 一次承認（テンプレートの回付先）→ 申込者アカウント通知 → 申込者ログイン（お知らせ／メニューのタブ）→ ポータルからの修正・確定・同意 → パスワード変更 → メンテナンス（通知履歴・パスワード初期化・初期化後のログイン）→ 一部修正（基準内／基準超）→ 確認 URL からの申込者差戻し・同意 → 最終承認 → 審査申請 → 審査差戻し → 再申請（前回の回付先が初期値）→ 審査完了 → 契約変更（基準内）→ 審査差戻し（復元）→ SC09「修正」で 20501 → 20101 → 契約変更の取消 → 契約変更（基準超）→ ポータルで同意 → 審査完了（メニューの領域：新規申込／契約変更1〜3、折りたたみ、過去の領域の参照）→ 申込取消（90101）
- 会社B：回付先なし申請 → 同意 → 事前確認 NG → 修正対応 → 事前確認 OK → 全体修正（変更項目の赤字表示）→ 引戻し
- 一括取込（正常行とエラー行）、管理者のマスタ画面、開発支援画面

スクリーンショットは `e2e/shots/` に保存される（git 管理外）。開発支援画面（`app.dev-tools.enabled=true`）と `extapi.mode=mock` を前提にしている。
